# Security

## Reporting a vulnerability

Report privately through [GitHub's advisory form](https://github.com/epheterson/immich-apple-silicon/security/advisories/new) rather than a public issue. Include what you found and how to reproduce it.

## What this does to your machine

[docs/security.md](docs/security.md) lists every network-facing surface, every file written outside `~/.immich-accelerator`, and how to undo each one.

## Supported versions

Fixes go into the current release. Please upgrade before reporting a problem with an older one.
